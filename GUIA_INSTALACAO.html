Sistema de Boas-Vindas Aquabeat

Guia Rápido de Instalação

📖 O que você encontrará neste guia:
Passo a passo completo para instalar o Sistema de Boas-Vindas em poucos minutos usando o instalador automático.

📋 Antes de Começar

Requisitos Mínimos:

  • Servidor Web: Apache 2.4+ ou Nginx
  • PHP: 7.4 ou superior
  • MySQL: 5.7 ou superior (ou MariaDB 10.2+)
  • Extensões PHP: PDO, PDO_MySQL, MySQLi, JSON, mbstring
  • Espaço em disco: Mínimo 50MB

O que você precisa ter em mãos:

  • Credenciais do banco de dados (usuário e senha)
  • Acesso ao servidor via FTP/SSH
  • Permissões de escrita no diretório

🚀 Instalação Automática (Recomendado)

Passo 1: Fazer Upload dos Arquivos

Extraia o arquivo sistema-boasvindas-aquabeat.zip e faça upload de todos os arquivos para o servidor.

⚠️ Importante: Mantenha a estrutura de diretórios. Todos os arquivos devem estar na mesma pasta.
Passo 2: Acessar o Instalador

Abra seu navegador e acesse:

http://seudominio.com.br/caminho-do-sistema/install.php

Ou se estiver em localhost:

http://localhost/boasvindas/install.php
Passo 3: Verificação de Requisitos

O instalador irá verificar automaticamente:

  • ✅ Versão do PHP
  • ✅ Extensões necessárias
  • ✅ Permissões de escrita

Se tudo estiver OK (verde), clique em "Próxima Etapa".

Se houver erros (vermelho), corrija conforme indicado e recarregue a página.

Passo 4: Configuração do Sistema

Preencha os dados solicitados:

Banco de Dados do Sistema:

  • Host: localhost (ou IP do servidor MySQL)
  • Nome do Banco: aquabeat_boasvindas (ou nome desejado)
  • Usuário: usuário do MySQL
  • Senha: senha do MySQL

Banco de Dados Externo (API - Vendas):

  • Host: localhost
  • Nome do Banco: mcaq_auditoria
  • Usuário: mcaq_auditoria
  • Senha: sign@2023DS

Usuário Administrador Inicial:

  • Nome: Seu nome
  • E-mail: seu@email.com
  • Senha: Escolha uma senha forte
🔐 Segurança: Escolha uma senha forte para o administrador! Você poderá alterá-la depois.
Passo 5: Instalação Automática

O instalador irá:

  • ✅ Criar o banco de dados
  • ✅ Criar todas as tabelas
  • ✅ Inserir dados iniciais
  • ✅ Criar o usuário administrador
  • ✅ Gerar o arquivo config.php
  • ✅ Desativar o instalador por segurança
Passo 6: Concluído!

Clique em "Acessar o Sistema" e faça login com as credenciais cadastradas.

🎉 Pronto! O sistema está instalado e pronto para uso!

🔧 Instalação Manual (Avançado)

Se preferir instalar manualmente ou o instalador automático não funcionar:

1. Criar Banco de Dados Manualmente
mysql -u root -p CREATE DATABASE aquabeat_boasvindas CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; exit;
2. Importar Estrutura
mysql -u root -p aquabeat_boasvindas < database.sql
3. Configurar config.php

Edite o arquivo config.php e altere as credenciais:

define('BV_DB_HOST', 'localhost'); define('BV_DB_NAME', 'aquabeat_boasvindas'); define('BV_DB_USER', 'seu_usuario'); define('BV_DB_PASS', 'sua_senha');
4. Criar Usuário Admin
mysql -u root -p aquabeat_boasvindas INSERT INTO usuarios (nome, email, senha, tipo) VALUES ('Admin', 'admin@aquabeat.com.br', MD5('admin123'), 'admin');

🐛 Problemas Comuns

❌ Erro: "Não consegue conectar ao banco"

  • Verifique se o MySQL está rodando
  • Confirme usuário e senha
  • Teste conexão: mysql -u usuario -p

❌ Erro: "Permissão negada"

chmod 755 /caminho/do/sistema chmod 644 /caminho/do/sistema/*.php

❌ Página em branco

  • Ative display_errors no PHP
  • Veja o log: /var/log/apache2/error.log
  • Verifique extensões PHP instaladas

❌ Vendas não aparecem

  • Verifique credenciais do banco externo em config.php
  • Confirme que a tabela titulos_analise existe
  • Teste conexão com banco externo

✅ Pós-Instalação

1. Primeiro Acesso
  • Faça login com as credenciais criadas
  • Altere IMEDIATAMENTE a senha do administrador
  • Verifique se o sistema está carregando corretamente
2. Criar Usuários
  • Acesse Usuários no menu
  • Crie contas para os atendentes
  • Defina permissões adequadas
3. Testar o Fluxo
  • Faça um teste completo de boas-vindas
  • Verifique se os dados estão sendo salvos
  • Teste os relatórios
4. Configurar Backup
# Adicionar ao crontab (backup diário às 2h) 0 2 * * * mysqldump -u usuario -p'senha' aquabeat_boasvindas > /backups/bv_$(date +\%Y\%m\%d).sql

🔐 Segurança em Produção

Checklist de Segurança:
  • ✅ Alterar senha padrão do admin
  • ✅ Usar HTTPS (SSL/TLS)
  • ✅ Implementar bcrypt para senhas (ao invés de MD5)
  • ✅ Configurar firewall do MySQL
  • ✅ Fazer backups regulares
  • ✅ Manter PHP e MySQL atualizados
  • ✅ Revisar permissões de arquivos
  • ✅ Remover install.php.bak do servidor
