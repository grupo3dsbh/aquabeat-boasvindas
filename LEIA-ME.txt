🚀 INSTALAÇÃO RÁPIDA (3 PASSOS)
══════════════════════════════════════════════════════════════════════════════

PASSO 1: FAZER UPLOAD
──────────────────────
• Extraia o arquivo sistema-boasvindas-aquabeat-completo.zip

PASSO 2: ACESSAR INSTALADOR
────────────────────────────
• Abra seu navegador
• Acesse: http://seudominio.com.br/caminho/install.php

─────────────────────────────

• Preencha os dados do banco de dados
• Crie o usuário administrador
• Clique em "Finalizar"
• Pronto! Sistema instalado!

🔧 INSTALAÇÃO MANUAL (ALTERNATIVA)
══════════════════════════════════════════════════════════════════════════════

Se preferir instalar manualmente:

1. Criar banco de dados:
   mysql -u root -p
   CREATE DATABASE aquabeat_boasvindas CHARACTER SET utf8mb4;
   exit;

2. Importar estrutura:
   mysql -u root -p aquabeat_boasvindas < database.sql

3. Editar config.php e alterar credenciais:
   - BV_DB_USER: seu usuário MySQL
   - BV_DB_PASS: sua senha MySQL

4. Criar usuário admin:
   mysql -u root -p aquabeat_boasvindas
   INSERT INTO usuarios (nome, email, senha, tipo) 
   VALUES ('Admin', 'admin@aquabeat.com.br', MD5('admin123'), 'admin');

5. Acessar: http://seudominio.com.br/caminho/login.php

🐛 PROBLEMAS COMUNS
══════════════════════════════════════════════════════════════════════════════

❌ Erro: "Não consegue conectar ao banco"
   → Verifique usuário e senha em config.php
   → Confirme que MySQL está rodando

❌ Erro: "Permissão negada"
   → Execute: chmod 755 /caminho/do/sistema
   → Execute: chmod 644 /caminho/do/sistema/*.php

❌ Página em branco
   → Ative display_errors no PHP
   → Veja /var/log/apache2/error.log
   → Verifique extensões PHP (php -m)

❌ Vendas não aparecem
   → Verifique credenciais do banco externo em config.php
   → Confirme que tabela titulos_analise existe


💾 BACKUP RECOMENDADO
